# Kolmogorov · Estadística Matemática

Página web del canal educativo **Kolmogorov**, de Daniel Vargas Zapata, dedicado a la estadística matemática con rigor académico y claridad pedagógica.

Temas: variables aleatorias, distribuciones, pruebas de hipótesis, regresión lineal, máxima verosimilitud, teorema central del límite, estadística bayesiana e información de Fisher.

- Canal: https://youtube.com/@danielvargaszapata4513
- Sitio: https://danielvar666.github.io

Es una página estática en un solo archivo (`index.html`).
